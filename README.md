# ФейсСкор — Android-приложение

Делаешь селфи → приложение само находит лицо (Google ML Kit, прямо на телефоне, без интернета) → измеряет симметрию и пропорции → ставит оценку от 1 до 10 с разбором.

## 1. Собрать и проверить на своём телефоне

1. Установи **Android Studio** (бесплатно): https://developer.android.com/studio
2. Распакуй архив, в Android Studio: **File → Open** → выбери папку `FaceScore`.
3. Подожди, пока внизу закончится «Gradle sync» (первый раз скачивается много всего, 5–15 минут).
   Если Studio предложит обновить версии (AGP, Kotlin, Gradle) — соглашайся.
4. На телефоне включи режим разработчика (Настройки → О телефоне → 7 раз нажать «Номер сборки»),
   затем в «Для разработчиков» включи **Отладку по USB**. Подключи телефон кабелем.
5. Нажми зелёный ▶ **Run** вверху. Приложение установится и откроется.

Сделай несколько фото себя и друзей. Если оценки всем кажутся заниженными или завышенными,
ориентиры можно подкрутить в начале файла `app/src/main/java/com/facescore/app/Scoring.kt`.

## 1б. Без Android Studio — сборка на GitHub

В проекте есть `.github/workflows/build.yml`: после загрузки на GitHub сервера GitHub сами
собирают `FaceScore.apk` и выкладывают его в раздел **Releases** репозитория.
Скачай APK с телефона и установи (разреши «Установку из неизвестных источников»).
Ход сборки видно во вкладке **Actions**.

## 2. Перед публикацией

- В `app/build.gradle.kts` замени `applicationId = "com.facescore.app"` на свой уникальный,
  например `com.ivanpetrov.facescore`. После первой загрузки в Google Play его поменять нельзя.
- При каждом обновлении увеличивай `versionCode` на 1.

## 3. Собрать файл для Google Play (.aab)

**Build → Generate Signed App Bundle or APK → Android App Bundle → Next →
Create new… (ключ подписи)**.

⚠️ Файл ключа (`.jks`) и пароль сохрани в надёжном месте. Без них не получится выпускать обновления.

Выбери вариант **release** → Finish. Готовый файл появится в `app/release/app-release.aab`.

## 4. Загрузить в Google Play

1. Зарегистрируйся в **Google Play Console**: https://play.google.com/console
   (разовый взнос 25 $, нужно подтвердить личность; владелец аккаунта должен быть совершеннолетним).
2. **Создать приложение** → заполни название, язык, «Приложение», «Бесплатное».
3. Заполни разделы в «Настройка приложения»:
   - **Политика конфиденциальности**: нужна ссылка. Текст лежит в `PRIVACY_POLICY.md`.
     Его можно опубликовать, например, бесплатно на Google Sites или в GitHub Pages.
   - **Безопасность данных (Data safety)**: приложение **не собирает и не передаёт** данные
     (фото обрабатывается только на устройстве).
   - **Возрастной рейтинг**: пройди анкету.
   - **Целевая аудитория**: выбирай 18+ или 16+. Если отметить детей, будет больше требований и проверок.
   - Реклама: «Нет».
4. **Страница в магазине**: короткое и полное описание, иконка 512×512 (`store/icon-512.png`),
   графический баннер 1024×500 и минимум 2 скриншота с телефона.
5. **Закрытое тестирование** — обязательно для новых личных аккаунтов:
   нужно **12 тестировщиков**, которые не выходят из теста **14 дней подряд**.
   Создай трек закрытого тестирования, загрузи `.aab`, добавь почты 12 друзей и знакомых,
   отправь им ссылку на участие. Они должны установить приложение и иногда им пользоваться.
6. Через 14 дней нажми **«Подать заявку на доступ к рабочей версии»**, потом создай релиз в
   **Рабочей версии (Production)** и отправь на проверку (обычно от нескольких дней до недели).

## Как это устроено

| Файл | Что делает |
|---|---|
| `MainActivity.kt` | Экраны: главный, загрузка, результат с разметкой на фото |
| `FaceAnalyzer.kt` | Находит лицо и ключевые точки через ML Kit Face Detection |
| `Scoring.kt` | Считает симметрию, пропорции и итоговую оценку |

Требования: Android 9+, targetSdk 36 (обязателен для новых приложений в Google Play с 31.08.2026).
